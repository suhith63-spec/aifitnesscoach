# Exercise Demonstration Videos

This directory contains exercise demonstration videos showing proper form for each exercise type.

## Video Files

- `bicep_curl_demo.mp4` - Bicep curl demonstration
- `push_up_demo.mp4` - Push-up demonstration  
- `shoulder_press_demo.mp4` - Shoulder press demonstration
- `pull_up_demo.mp4` - Pull-up demonstration
- `squat_demo.mp4` - Squat demonstration

## Video Specifications

- **Duration**: 15-20 seconds (loopable)
- **Resolution**: 720p or 1080p
- **Format**: MP4
- **Branding**: Forever Fit logo on workout outfit
